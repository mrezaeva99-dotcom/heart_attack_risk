# ❤️ Heart Attack Risk Predictor API

Проект веб-сервиса по предсказанию риска сердечных приступов на основе медицинских данных пациентов.  
Целевая переменная: `Heart Attack Risk (Binary)`.

## Описание
Проект представляет собой API на базе FastAPI, интегрированное с предобученной моделью CatBoost. Программа принимает CSV-файл с данными, проводит их очистку и трансформацию, после чего выдает прогноз (0 — низкий риск, 1 — высокий риск).

## Структура проекта
├── app/ # FastAPI приложение
│ └── main.py # основной файл приложения

## Как запустить

1. **Клонируйте репозиторий или перейдите в папку проекта:** cd heart_attack_risk```

2. **Активируйте окружение:** для Windows: python -m venv venv;

Для macOS/Linux: python3 -m venv venv;

3. **Установите зависимости:** pip install -r requirements.txt

4. **Запустите сервер:** python main.py

## После запуска перейдите по адресу:
http://127.0.0.1:8000  

## Класс HeartAttackPredictor
- `__init__` – задаёт пути к файлам модели.
- `load_assets()` – загружает модель CatBoost, scaler, список признаков и порог.
- `_preprocess()` – выполняет очистку и подготовку данных (удаление лишних колонок, кодирование пола, масштабирование).
- `predict()` – возвращает предсказания и вероятности.

## Результаты
- Лучшая модель: CatBoost с балансировкой классов.
- Метрика: ROC-AUC (выбрана из‑за дисбаланса классов).
- На валидации: ROC-AUC = 0.525, Recall = 0.50, Precision = 0.38.
- Порог предсказания подобран как 0.4, чтобы доля класса 1 соответствовала обучающим данным.
